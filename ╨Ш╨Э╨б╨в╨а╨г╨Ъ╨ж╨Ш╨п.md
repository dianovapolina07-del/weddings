# Свадебная галерея для VK Mini App

Это готовая статическая версия галереи Татьяны Окуловой: 14 фотографий, вертикальный коллаж 9:16, плавное движение и две кнопки внизу.

## Самый простой способ публикации через GitHub Pages

1. Откройте https://github.com и создайте бесплатный аккаунт или войдите в существующий.
2. Нажмите **New repository**.
3. Назовите репозиторий `weddings` и выберите **Public**.
4. Нажмите **Create repository**.
5. Нажмите **Add file → Upload files**.
6. Распакуйте этот архив и загрузите все файлы и папку `assets` в репозиторий. В корне должны лежать `index.html`, `app.js`, `style.css`, `media.json` и папка `assets`.
7. Нажмите **Commit changes**.
8. Откройте **Settings → Pages**.
9. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите **Save**.
10. Через несколько минут GitHub покажет адрес вида:

   `https://ВАШ_ЛОГИН.github.io/weddings/`

## Подключение к VK Mini App

В настройках приложения VK откройте **Размещение** и вставьте полученный адрес GitHub Pages в поле **URL** для мобильного приложения, десктопной версии и мобильной версии сайта. В режиме разработки можно указать тот же адрес. После сохранения откройте ссылку приложения VK и проверьте галерею.

## Важно

Не переименовывайте файлы внутри папки `assets` и не загружайте только один `index.html`: фотографии должны быть загружены вместе с остальными файлами.
